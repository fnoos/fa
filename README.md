# فانوس 🌙

**رفیقِ شب‌های تردید و آگاهی**

فانوس فقط یک صفحه نیست…
گاهی آدم بین شلوغیِ دنیا، بین خبرها، استرس‌ها، سرعتِ زندگی، و هزار تا صدای بلند…
فقط به یک نورِ کوچک احتیاج دارد. نه نوری که چشم را خیره کند، بلکه نوری که راه را نشان بدهد. فانوس، برای همین ایجاد شده است…

## ویژگی‌ها

- نمایش پست‌ها با دسته‌بندی و جستجو
- تم تاریک و روشن
- تغییر رنگ تم
- تنظیم سایز فونت
- اشتراک‌گذاری متن پست‌ها
- پخش فایل صوتیِ اختیاری
- انیمیشن‌های نرم بین صفحات (View Transitions)

## محتوا

مطالب به‌صورت فایل‌های Markdown در پوشه‌ی `src/content/posts` ذخیره می‌شوند. نام هر زیرپوشه، دسته‌بندی آن مطالب است:

```
src/content/posts/
├── الحاد/
│   └── نام-mطلب.md
├── حال خوب/
│   └── نام-mطلب.md
└── اخلاق اسلامی/
    └── نام-mطلب.md
```

- هشتگ‌ها با دو فاصله از هم جدا می‌شوند: `hashtags: "#آگاهی  #پرسشگری"`
- تاریخ شمسی به‌صورت متن در frontmatter نوشته می‌شود
- فایل صوتی اختیاری است: `audio: /audio/sample.mp3`

## تکنولوژی‌ها

- **Astro** — فریم‌ورک مدرن برای سایت‌های ایستا (Content Collections)
- **React** — برای بخش‌های تعاملی (جزیره)
- **Tailwind CSS v4** — استایل‌دهی سریع
- **SCSS** — پشتیبانی از Sass
- **Framer Motion** — انیمیشن‌های روان
- **Vazirmatn** — فونت فارسی
