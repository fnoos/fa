# فانوس 🌙

**رفيق ليالي التردد والبحث**

فانوس ليس مجرد صفحة…
أحيانًا، وسط ضجيج العالم، بين الأخبار والضغوط وسرعة الحياة وآلاف الأصوات العالية…
يحتاج الإنسان فقط إلى ضوء صغير. ليس ضوءً يبهر العين، بل ضوءً يرشد الطريق. فانوس خلق لهذا…

## الميزات

- عرض المشاركات مع التصنيف والبحث
- الوضع الداكن والفاتح
- تغيير لون السمة
- ضبط حجم الخط
- مشاركة النصوص
- التشغيل الصوتي الاختياري
- انتقالات سلسة بين الصفحات (View Transitions)

## المحتوى

تُخزَّن المشاركات كملفات Markdown في مجلد `src/content/posts`. اسم كل مجلد فرعي هو تصنيف المحتوى:

```
src/content/posts/
├── إلحاد/
│   └── اسم-مشاركة.md
├── حال جيد/
│   └── اسم-مشاركة.md
└── أخلاق إسلامية/
    └── اسم-مشاركة.md
```

- الفواصل (الهاشتاغات) تفصل بينها مسافتان: `hashtags: "وعي  تساؤل"`
- يُكتَب التاريخ في frontmatter بصيغة هجرية (قمرية)
- الملف الصوتي اختياري: `audio: /audio/sample.mp3`

## التقنيات

- **Astro** — إطار عمل حديث للمواقع الثابتة (Content Collections)
- **React** — للأجزاء التفاعلية (الجزر)
- **Tailwind CSS v4** — تصميم سريع
- **SCSS** — دعم Sass
- **Framer Motion** — حركات سلسة
- **Estedad** — الخط (مستضاف ذاتيًا داخل المشروع)
